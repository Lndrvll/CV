# Wiki Schema\n\n## Overview\nThis document defines the conventions for the LLM Wiki in the CV vault.\n\n## Structure\n- : Immutable source documents.\n- : LLM-generated synthesized content.\n- : The map of all wiki content.\n- : Chronological record of all operations.\n\n## Page Types\n- **Source Summary**: One page per raw source. Focuses on key takeaways.\n- **Entity**: A page for a person, organization, or specific project.\n- **Concept**: A page for a theme, skill, or abstract idea.\n- **Synthesis**: High-level analysis connecting multiple sources.\n\n## Workflows\n### Ingest\n1. Read raw source.\n2. Discuss takeaways with user.\n3. Create/Update Source Summary in .\n4. Update relevant Entity/Concept pages.\n5. Update .\n6. Log the operation in .\n\n### Query\n1. Search  for relevant pages.\n2. Synthesize answer with citations.\n3. (Optional) File the answer as a new Synthesis page.\n\n### Lint\n1. Check for contradictions.\n2. Identify orphan pages.\n3. Suggest missing links or data gaps.
